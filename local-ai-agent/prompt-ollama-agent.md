# Implementation task: local LLM MCP server (Ollama backend)

## Context

I run Claude Code as my primary AI coding assistant. I want to add a local
Ollama model as a secondary, free, offline-capable tool that Claude can call
for cheaper/faster subtasks — summarizing long text, generating drafts, simple
code, classification, etc. — so I don't burn API credits on every small task.

The integration point is the Model Context Protocol (MCP): a JSON-RPC server
that Claude Code spawns as a subprocess and calls via stdin/stdout. I already
have `mcp_server.py` (in the same directory as this file). Your job is to
install dependencies, pull the right Ollama model, and wire everything into
my Claude Code config so the tool is available immediately.

## Prerequisites to verify first

1. Python 3.10+ is installed (`python3 --version`)
2. `pip` is available (`pip --version` or `pip3 --version`)
3. Ollama is installed and running (`ollama list` should respond)
4. Claude Code CLI is installed (`claude --version`)

If any prerequisite is missing, install it:
- Ollama: `curl -fsSL https://ollama.com/install.sh | sh`
- pip: `sudo dnf install python3-pip` (Fedora) or `sudo apt install python3-pip`

## Steps to implement

### 1. Install Python dependency

```bash
pip3 install --user requests
```

Verify: `python3 -c "import requests; print('ok')"` should print `ok`.

### 2. Pull the recommended Ollama models

For coding tasks (best quality on 64GB RAM):
```bash
ollama pull qwen2.5-coder:32b
```

For general tasks (faster, lower RAM):
```bash
ollama pull mistral-nemo
```

Verify Ollama responds:
```bash
curl -s http://localhost:11434/api/tags | python3 -m json.tool | grep name
```

### 3. Find the absolute path to mcp_server.py

```bash
realpath mcp_server.py
```

Note this path — you need it in the next step.

### 4. Add the MCP server to Claude Code

Claude Code reads MCP server config from `~/.claude/mcp.json`.
Create or merge the following into that file (replace `/ABSOLUTE/PATH` with the
path from step 3):

```json
{
  "mcpServers": {
    "local-llm": {
      "command": "python3",
      "args": ["/ABSOLUTE/PATH/TO/mcp_server.py"],
      "env": {
        "LOCAL_LLM_BACKEND": "ollama",
        "OLLAMA_MODEL": "qwen2.5-coder:32b",
        "OLLAMA_URL": "http://localhost:11434"
      }
    }
  }
}
```

If `~/.claude/mcp.json` already exists, merge the `"local-llm"` key into the
existing `"mcpServers"` object without overwriting other servers.

### 5. Verify the MCP server starts cleanly

```bash
echo '{"jsonrpc":"2.0","method":"initialize","id":1,"params":{"protocolVersion":"2024-11-05","capabilities":{},"clientInfo":{"name":"test","version":"1"}}}' \
  | OLLAMA_MODEL=qwen2.5-coder:32b python3 /ABSOLUTE/PATH/TO/mcp_server.py
```

Expected output (one line):
```json
{"jsonrpc": "2.0", "id": 1, "result": {"protocolVersion": "2024-11-05", "capabilities": {"tools": {}}, "serverInfo": {"name": "local-llm-mcp", "version": "1.0.0"}}}
```

### 6. Restart Claude Code and test

Open a new Claude Code session. Ask it:
```
Use the local_llm tool to summarize: "Fedora is a Linux distribution sponsored by Red Hat."
```

Claude should call the tool and return a summary generated by your local model.

## Optional: systemd service for Ollama

If Ollama isn't running on boot:
```bash
sudo systemctl enable --now ollama
```

## How Claude will use this

Once wired in, Claude Code sees a `local_llm` tool with this description:

> Run a prompt through a secondary LLM (local Ollama model). Use for tasks
> where speed/cost matter more than peak quality: summarizing long text,
> simple code generation, classification, translation, drafts.

Claude decides autonomously when to delegate. You can also instruct it
explicitly: "use local_llm to summarize this file before we discuss it."

## Switching models at runtime

You can override the model per-call by passing a `model` argument:
- `"model": "mistral-nemo"` — fast, low RAM
- `"model": "qwen2.5-coder:32b"` — best for code
- `"model": "llama3.3:70b"` — best general quality on 64GB RAM

## Troubleshooting

| Symptom | Fix |
|---|---|
| `Connection refused` on Ollama URL | Run `systemctl start ollama` |
| `ModuleNotFoundError: requests` | `pip3 install --user requests` |
| MCP server not found by Claude | Check absolute path in `mcp.json`, restart Claude |
| Model too slow | Switch to `mistral-nemo` or `qwen2.5-coder:7b` |
| Out of memory | Use a smaller quantization: `ollama pull llama3.3:70b-instruct-q4_K_M` |
